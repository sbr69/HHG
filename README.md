# HH Goa 2026 — Builder Pass

Claim your official HH Goa 2026 Builder Pass. Drop a portrait, enter your
details, and a print-grade credential is rendered live in your browser — ready
to share to X with `#FrameInGoa`. Nothing is uploaded; the pass is drawn
entirely client-side on `<canvas>`.

## Stack

- TanStack Start (SSR)
- React 19
- Tailwind CSS v4
- Canvas-based pass rendering

## Development

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```
